# Analytical Classification with Least Squares 📐

Этот проект демонстрирует **аналитический подход к решению задачи бинарной классификации** с использованием метода наименьших квадратов. В отличие от итеративных методов (например, градиентного спуска), здесь решение находится за один шаг через матричные операции.

## 🎯 Что делает этот код?

Код находит оптимальную разделяющую прямую для двух классов точек, используя **замкнутую форму решения** (closed-form solution) задачи классификации. Вместо обучения с помощью итераций, веса классификатора вычисляются аналитически:
`w = (XᵀX)⁻¹ · Xᵀ · y`
где `X` — матрица признаков с добавленным смещением (bias term), `y` — вектор меток классов.

## 📐 Математическая основа

### Постановка задачи
Даны точки двух классов с метками `+1` и `-1`. Необходимо найти линейную разделяющую границу:
`w₀·x₁ + w₁·x₂ + w₂ = 0`
Или в матричной форме:
`X·w = y`

### Решение методом наименьших квадратов
Поскольку система может быть переопределена (точек больше, чем параметров), ищем решение, минимизирующее квадратичную ошибку:
`minimize ||X·w - y||²`
Оптимальное решение:
`w = (XᵀX)⁻¹ · Xᵀ · y`

### Расширенная матрица признаков
В код добавляется столбец единиц для учёта свободного члена (bias):
```python
x_train = np.hstack((x_train, np.ones((len(x_train), 1))))```

**⚙️ Алгоритм шаг за шагом**
**1. Подготовка данных**
```python
x_train = np.hstack((x_train, np.ones((len(x_train), 1))))```
Добавляем столбец единиц для учёта свободного члена.

**2. Вычисление вспомогательных сумм**
```python
pt = np.sum([x*y for x,y in zip(x_train, y_train)], axis=0)```
Вычисляем Xᵀ·y — сумму произведений признаков на метки.

```python
xxt = np.sum([np.outer(x, x) for x in x_train], axis=0)```
Вычисляем Xᵀ·X — сумму внешних произведений векторов признаков.

**3. Решение системы**
```python
w = np.dot(pt, np.linalg.inv(xxt))```
Находим веса через обратную матрицу: w = (XᵀX)⁻¹ · (Xᵀy)

**4. Построение разделяющей линии**
Из уравнения w₀·x₁ + w₁·x₂ + w₂ = 0 выражаем x₂:
```python
line_y = [-x*w[0]/w[1] - w[2]/w[1] for x in line_x]```
