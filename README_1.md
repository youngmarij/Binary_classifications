# Binary Classification with Perceptron 📊

Этот мини-проект демонстрирует работу **простейшего линейного классификатора** (перцептрона) на синтетических данных. Проект состоит из двух модулей: генерация двухклассовых данных и обучение классификатора с визуализацией результатов.

## 📁 Структура проекта
project/

├── data_generate.py # Генерация синтетических данных

└── classification.py # Обучение перцептрона и визуализация

## 🎯 Что делает этот код?

### 1. Генерация данных (`data_generate.py`)

Создаёт два класса точек в 2D-пространстве:
- **Класс 0** (красный) — центрирован вокруг точки `(2, 2)`
- **Класс 1** (синий) — центрирован вокруг точки `(-2, -2)`

Особенности генерации:
- Используется многомерное нормальное распределение
- Добавляется шум для реалистичности данных
- Данные случайно перемешиваются

### 2. Обучение классификатора (`classification.py`)

Реализует **алгоритм перцептрона** для поиска разделяющей прямой:
`a(x) = sign(x₁·w₁ + x₂·w₂)`
Где `w` — веса классификатора, которые настраиваются в процессе обучения.

## ⚙️ Параметры модели

| Параметр | Значение | Описание |
|----------|----------|----------|
| `n_samples` | 100 | Количество точек в каждом классе |
| `noise` | 0.5 | Уровень шума (дисперсия распределения) |
| `random_seed` | 42 | Фиксация случайности для воспроизводимости |
| `N` | 50 | Максимальное количество эпох обучения |
| `L` | 0.1 | Скорость обучения (learning rate) |
| `e` | 0.1 | Дополнительное обновление весов |

🧠 **Алгоритм обучения**:
for n in range(50):  # эпохи обучения

    for i in range(len(X)):  # проход по всем точкам
    
        if Y[i] * a(X[i]) < 0:  # ошибка классификации
        
            w[0] = w[0] + L * Y[i]  # обновление веса
            
            last_error_index = i

**Правило обновления весов**
Если точка классифицирована неверно (Y[i] * a(X[i]) < 0), вес корректируется:
`w_new = w_old + L · Y[i]`

**⚠️ Ограничения алгоритма**

**Линейная разделимость** — работает только если классы можно разделить прямой

**Чувствительность к шуму** — выбросы могут сильно влиять на результат

**Сходимость** — при плохих начальных условиях может не сойтись

**Фиксированный вес** w[1] = w[0] — в текущей реализации второй вес не обучается
